### Solucion 
En este reto se nos proporciona un archivo `.tar`en el cual tiene de nombre `1000.tar`. En este caso para analizar el archivo uso el comando `tar -xf 1000.tar`. Este comando me devuelve otro archivo tar llamado `999.tar`, por lo que vuelvo a aplicar el comando `tar -xf 999.tar`y obtuve el archivo `998.tar`. Por lo que suponemos que la bandera estará en el archivo `1`. Pero necesito antes descomprimir otros 997 archivos para llegar. Por lo que hago uso de un script en bash:eso simplemente se hace con un for, aqui lo muestro =. 

```

```
for ((i = 1000;i>=1;i--)); do
        archivo="$i.tar"
        if [ -f "$archivo" ]; then
                echo "Extrayendo $archivo"
                tar -xf "$archivo"
        else
                echo "No existe $archivo"
        fi
done
